# Make the AI Judge Laugh: Office Jokes

Deterministic `program/v1` entry for the [make.fun Office Jokes bounty](https://make.fun/r/41fw6r6c) (`u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a`).

## Usage

Requires Node 22.18+ (zero external dependencies):

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

When run inside the make.fun sandbox, `main.ts` writes a single UTF-8 one-line office joke (1–199 characters, no trailing newline) deterministically to `/output/entry.txt`.
